# Hero Video Asset Directory

This directory hosts the video assets for the landing page Hero section.

## Expected Asset

- **File name:** `hero-travel.mp4`
- **Location:** `D:\travel-application\client\public\videos\hero-travel.mp4`
- **Format:** MP4 (H.264 video codec, AAC audio or muted)
- **Recommended Resolution:** 1920x1080 (1080p) or 1280x720 (720p)
- **Recommended File Size:** 3MB - 12MB for fast loading

## Fallback Behavior

If `hero-travel.mp4` is not present in this directory or fails to load, the application will automatically display a layered atmospheric gradient fallback with ambient lighting and contrast-enhancing dark overlays.
